# Adversarial validation: global mineral plant workspace

The full view, layout, source/provenance and release acceptance matrix is in [plant-workbench-tdd.md](../../plant-workbench-tdd.md). The rows below link each SDD requirement to a test that actively rejects a regression.

| requirement | adversarial check | gate |
|---|---|---|
| WP-001 | A collapsed view registry or global-only asset selection is planted; the regression test requires separate representations and area-specific selectors. | `frontend/src/App.test.tsx::adversarial: the plant workspace cannot collapse all areas into one diagram mode` |
| WP-002 | An area is removed, left empty or assigned the same core graph as another; the regression test enumerates every required area and requires unique detail graph signatures. | `frontend/src/workbench/areas.test.ts::adversarial: every required area has its own non-empty detail graph` |
| WP-003 | A physical asset is duplicated across area ownership or left unassigned; exact coverage and uniqueness fail. | `frontend/src/workbench/areas.test.ts::adversarial: assets cannot be duplicated or left outside area ownership` |
| WP-004 | An adjacent asset is moved into the selected area's core or boundary streams are omitted; the test requires explicit incoming/outgoing connectors and a bounded core set. | `frontend/src/workbench/areas.test.ts::adversarial: neighboring equipment stays boundary context outside an area core` |
| WP-005 | A water-bearing slurry/solution stream is omitted because its material is not `water`; the test requires positive water contribution routes with identity preserved. | `frontend/src/workbench/areas.test.ts::adversarial: slurry and solution water contributions cannot disappear from balance routes` |
| WP-006 | A wrong asset, tag, unit or older sequence is injected; validation must reject it without overwriting retained history. | `frontend/src/workbench/model.test.ts::adversarial: refuses wrong asset, unit and older delivery without overwriting history` |
| WP-007 | An external glTF resource or unknown asset mapping is planted; scene validation must refuse the import. | `frontend/src/workbench/scene.test.ts::adversarial: external resources and unknown mappings are refused` |
| WP-008 | An unknown area ID is supplied; the model must throw instead of silently showing the global graph. | `frontend/src/workbench/areas.test.ts::adversarial: an unknown area cannot silently resolve to the global graph` |
| WP-009 | Area activation from a global view must preserve its representation; the regression gate rejects automatic switching away from the selected site plan, schematic or 3D view. | `frontend/src/App.test.tsx::adversarial: opening an area preserves the selected site, schematic or 3D representation` |
| WP-010 | Engine links and replay channels from other areas are planted; area filtering must retain only core assets, while water balance includes all participating assets and global scope retains the whole plant. | `frontend/src/workbench/areas.test.ts::adversarial: engine evidence and method-comparison channels stay inside the selected area` |
| WB-014 | The route, case, view group or sub-view is changed on Focus entry/exit, or the runner allows bypassing the required Focus check. | `frontend/src/gate-script.test.ts::adversarial: arguments that redirect what G18 measures are refused while Focus is required (the review plant, WB-014)` |
| WB-015 | The App kind is unknown or a Focus waiver is invalid, incomplete or inconsistent with the SDD; guard mutations must be rejected. | `tests/adversarial/test_app_kind.py::test_an_unknown_app_value_fails` and the remaining `test_*` cases in `tests/adversarial/test_app_kind.py` |
