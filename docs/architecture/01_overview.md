# One connected operating picture

The authored graph has 36 equipment assets and 47 directed streams spanning ore arrival, crushing, grinding/classification, flotation, water recovery, leach/SX/EW and tailings context. Asset IDs are stable across the scene, diagram, selector, source bindings and evidence catalog. The graph is not an industrial engineering exchange standard or a site survey.

The workbench stores selected asset, case, availability time, method, traversal and source. Every view receives the same state. Source evidence retains original engine case identity; the 16-channel transport study is separate authored synthetic evidence. Selecting a geometry node changes the same asset as keyboard selection or a diagram click.

Imported glTF uses extras.assetId. World-space labels and stream endpoints follow imported hierarchy transforms. Missing mapped assets lose their spatial labels/pipes rather than retaining misleading old anchors. Status labels work independently of imported materials. Diagram coordinates remain a graph reference, not a replacement site drawing.
