# Data, source identity and rights

`derived/` contains compact public exports: one authored plant graph, twelve scenario traces and manifests, engine evidence, fitted-model metadata, measured benchmark and paired analysis, downstream references, readiness and the case index. Raw upstream downloads and model binaries stay in external roots.

The connected observations are authored synthetic known-truth sequences, not mine measurements. Four released packages are actually executed: minehaulsim uses Apache-2.0; bedblend, milldem and oreblocks use MIT. Ten MIT public source artifacts are read at exact commit, byte count and SHA-256. Their engine cases keep their original identity; binding an example to an asset is context, not a claim that the example was measured at that asset.

The authoritative upstream manifest is [sources/engines.lock.json](sources/engines.lock.json); computed provenance and metric paths are [derived/engine-evidence.json](derived/engine-evidence.json). ChancaDEM, OreFlow, PitForge, CutoffGrade, FragmentIQ, FrothSeg, TailWatch, RotorVitals, StockTwin and DispatchLab supply artifact evidence. minehaulsim, bedblend, milldem and oreblocks supply executed package evidence. Private or unpublished sources are explicitly unavailable.

Sixteen reference tag definitions bind tag ID, asset ID and canonical unit. The live gateway accepts only configured bindings matching that catalog and graph revision. It retains source-change time, server confirmation time, receipt time, sequence and quality. Site observations stay in bounded browser memory during the connection; they are not committed to this public dataset.

Every trace carries per-method/channel evidence lag. Aligned scores are displayed with the earlier raw observation they describe, not a later reading at the snapshot availability time. The benchmark counts rejected and unscorable values separately. Its noise scale is fixed at one across four severity levels.

MIT covers authored repository artifacts. Upstream license and provenance remain attached to each record; a hash verifies content integrity, not scientific validity or ownership beyond those declared rights. No site data rights are implied.
